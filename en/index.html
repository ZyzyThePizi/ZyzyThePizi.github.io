Room 02/10 · Archive

Data pipeline · 2026

pokemon-price-data

A daily git-scraping pipeline that turns a browser-blocked price guide into static JSON anyone can fetch.

Problem

Cardmarket’s daily price guide is public and free, but it is served without CORS or gzip headers, so a web app cannot fetch it directly.

Solution

A scheduled GitHub Actions job downloads the source daily, skips unchanged files by ETag, slims the data into a compact row format and splits per-product history into 1,000 shards so a client downloads only what it needs. GitHub Pages serves it with CORS and gzip.

Room 04/10 · Sealed Gate

Security audit · 2026

Model-Gate

Security audit and hardening of a fork of an open-source VS Code extension.

Problem

A single-maintainer, auto-updating Marketplace extension holds a live access token and can run commands on developer machines. One compromised update would reach every install.

Solution

I wrote a threat model and an ID-tracked findings register, then moved the code into a reviewed fork: a pnpm + Turborepo monorepo with a shared core package, separate VS Code and browser extensions, its own build and distribution, and fixes scheduled in phases.

Room 07/10 · Terrarium

Self-hosted server hub · 2026

Local Minecraft Server

Minecraft servers on your own machines, in one shared web hub: every machine is an island, and modpacks install from search in one click.

Problem

Running a modded server at home takes many manual steps: the server side of the modpack, the matching loader and Java, addresses and ports. And when several people run servers on their own machines, there is no shared place to manage and share them safely without user accounts.

Solution

Every machine runs a Node backend (Hono) with its own Ed25519 machine key and gets a public HTTPS address through Tailscale Funnel. The static React hub on GitHub Pages keeps the machines in the browser only: it pins their keys on first contact, and sign-in works with a password or a revocable invite link, with rotating tokens and an audit log. Several servers can run on one machine within a shared RAM budget. It installs CurseForge or Modrinth modpacks from search: client-only mods are skipped, but anything a server-side mod requires according to the jars’ own metadata is put back. Under the console, commands are buttons: the everyday ones up front, then a searchable catalogue with descriptions, filtered to the server’s Minecraft version. A stopped server’s player data or world can be wiped with one button. The hub works in English and Hungarian and is a live Three.js archipelago: every machine is an island, every server a beacon.
